# Buckeye Trail completion tracker

Personal Buckeye Trail progress and section-planning map generated from AllTrails GPX activities.

**Live map:** https://guntherb7.github.io/buckeye-trail-tracker/

- Completed mileage is estimated by matching recorded tracks to the OpenStreetMap Buckeye Trail relation.
- Suggested hikes follow mapped route geometry and do not guarantee parking, legal access, or current trail conditions.
- Verify plans with current [Buckeye Trail Association section information](https://www.buckeyetrail.org/sections) and the [FarOut Buckeye Trail guide](https://faroutguides.com/buckeye-trail-map/).

This is a personal planning estimate, not an official Buckeye Trail Association completion record.
